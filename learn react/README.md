# React learning examples

Small, practical React examples arranged by topic. Each lesson folder contains an `App.jsx` example and a `README.md` explaining the important ideas.

## Run the examples

1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev`.

The root app provides a lesson switcher. Read the lesson README beside the code before moving to the next topic.

## Lessons

- `01-components-props`: component composition and props
- `02-state-events`: `useState` and event handlers
- `03-lists-conditional`: rendering collections and empty states
- `04-forms`: controlled inputs and submit handling
- `05-effects-fetching`: `useEffect`, loading, and cleanup
- `06-custom-hooks`: extracting reusable stateful logic
- `07-context`: sharing app-level data without prop drilling
- `08-reducer`: predictable updates with `useReducer`
